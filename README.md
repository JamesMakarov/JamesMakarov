## Selected projects

### [Answer Sheet Reader](https://github.com/JamesMakarov/answer-sheet-reader)

Web application for automated answer-sheet processing.

**Python · Django · PostgreSQL · Docker · C/C++ · ctypes**

- user authentication and profiles;
- image upload and review workflow;
- native C/C++ image-processing library integrated with Python;
- automated answer extraction and scoring;
- containerized application and database.

### [JamesVox](https://github.com/JamesMakarov/voice-system-jamesvox)

Desktop automation system for scheduled audio and voice announcements.

**Python · CustomTkinter · Pygame · Edge TTS · ElevenLabs**

- scheduled events and playlists;
- text-to-speech announcements;
- audio ducking;
- bilingual announcements;
- local persistence and system-tray integration.

### [Dijkstra Visualizer](https://github.com/JamesMakarov/dijkstra-visualizer)

Interactive JavaFX application for visualizing Dijkstra's shortest-path algorithm.

**Java · JavaFX · Graph Algorithms · Multithreading**

- interactive graph editing;
- weighted directed edges;
- animated algorithm execution;
- event-based separation between algorithm and UI;
- background execution with JavaFX UI synchronization.

### [C++ Ray Tracer](https://github.com/JamesMakarov/ray-tracer-cpp)

CPU renderer implemented from scratch for a Computer Graphics course.

**C++ · Computer Graphics · Linear Algebra**

- geometric intersection tests;
- perspective camera;
- Blinn-Phong lighting;
- shadows and textures;
- transformation matrices;
- interactive pixel picking.

### [Numerical Methods](https://github.com/JamesMakarov/Metodos-Numericos)

Implementation and comparison of iterative methods for linear systems.

**C++ · Jacobi · Gauss-Seidel · Numerical Computing**

**Oz · Haskell · Declarative Programming**
